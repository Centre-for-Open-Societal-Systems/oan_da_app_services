# APISIX gateway config

`adc.yaml` and `k8s/templates/` are generated by `generate_apisix_config.py`. Do not edit them.
Same layout and tooling as `oan_farmer_app_service/apisix/`; shared logic is in
`oan_auth_service/gateway_apisix.py`.

```bash
# From a bench's sites/ directory (Frappe writes its log to ../logs), with da_services importable:
PYTHONPATH=<this repo> python3 <this repo>/apisix/generate_apisix_config.py
```

Routes are the ones declared with `router.prefixed` (read back with `declared_routes("da_services")`); the
tier is picked by the generator from the method and whether the route is public. `oan_auth_service`'s own
`/v1/auth/*`, `/v1/admin/*` and `/v1/notifications/*` are added with `gw.with_auth_routes`, which refuses a
(method, path) that this app also declares. Public paths drop Frappe's `/api` (`/v1/da-services/...`); a
service-level `proxy-rewrite` puts it back.

## Install on oan_dev (Helm)

`k8s/` is a Helm chart (`oan-da-services-gateway`). Jenkins (stage "develop → gateway (apisix)") runs
`ci/deploy-gateway.sh`, which installs it as release `da-services-gateway` in namespace `da-app` with
`helm/environments/dev/oan-da-services-gateway.yaml`, after the app release `da-services`
(`ci/deploy-helm-dev.sh`). The public host is `da-services.development.oanstaging.com`; APISIX serves it
with the dev wildcard certificate, so the chart has no ApisixTls.

Environment read when the file is generated: `APISIX_REDIS_HOST`, `APISIX_REDIS_PORT`, `CORS_ORIGINS_REGEX`.
Read by ADC at sync time: `DA_SERVICES_UPSTREAM_HOST`, `FRAPPE_SITE_NAME`.
